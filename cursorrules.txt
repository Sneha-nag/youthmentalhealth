# Project Context: Youth Mental Health Risk Model
- Prefer modular Python architecture: keep data loading (data/), modeling (models/), and serving (api/) separate.
- Ensure all data transformations are vectorized using Pandas/NumPy (no explicit loops over rows).

- Log ML experiments using MLflow tracking rather than plain print statements.
